# Quote check

The agent put it in quote marks, and the source never said those words. The agent that wrote it always thinks it copied right, so asking it again only gets a yes. This skill sends a different agent to the source to search those exact words, and it changes nothing without your yes.

In our run, one video had two on-screen quote cards that were not the source's exact words. A second agent caught both against the live page before anything posted. That is one run, not a rate.

## The principles
1. Quote marks promise the exact words. Anything else is a paraphrase.
2. The agent that wrote the quote cannot be the one that checks it.
3. A source nobody could open is unverified, never a pass.

## Steps
1. List every quote in the draft and number them. Include captions, slides and on-screen cards.
2. For each quote, the writing agent pastes the source's sentence and the link.
3. Start a different agent, a fresh subagent. Give it only the numbered list. It opens each link and searches the page's own text for the exact words in the quote, not a summary of the page.
4. For a translated quote, it searches the original words. The quote keeps its marks only with a visible "translated" label and the original kept beside it.
5. Report each quote, with the line found:
   - **Exact**: the same words are on the page.
   - **Reworded**: the page says it in other words, or words are missing inside the marks.
   - **Unverified**: the source could not be opened, or no line on it says this. Say which.
6. For each reworded quote, propose one fix: fix the words to match the line found, or take off the quote marks and write "according to". Show the list and ask "Apply these?" Change the draft only after a yes.
7. Send every changed quote back to the second agent, and report the new result.

## Rules
- Dropped words count as reworded, even when the meaning survives.
- A paraphrase with a name and no quote marks is fine.
- Use "according to" only when the line found says the same thing.
- An unverified quote stays marked unverified until someone opens the source.
- Exact means the words match the page. It does not mean the check caught everything.
