# Report endings

The report said "nothing new", and the agent never read the source. A blocked page and a quiet day look the same in a summary, because the agent writes about what it got and says nothing about what it did not get. This skill makes every report say what it read, what failed, what changed, what it skipped and what needs you.

## The principles
1. A quiet report may be a failed read. Silence proves nothing until every source is accounted for.
2. A failure goes into the report. It is never a reason to leave something out.
3. New means new since the last run. Old items repeated hide the new ones.
4. A skip without a reason looks the same as a miss.
5. The person reads the top first, so the one decision goes there.

## Steps
1. Before reading, list every source the run should open. The report will be checked against this list.
2. Open each source and record what happened. Either it was read, or it failed with the error the agent saw (for example "403 forbidden", "timed out" or "page empty").
3. Find the date of the last run. Keep it in a short log file in the project, with the items that run reported. If there is no log, say this is the first run.
4. Compare what you read with the log. Mark each item new or updated, drop anything already reported, and then update the log.
5. List every item you did not read, with the reason: behind a paywall, a video, too long, off topic.
6. Write the report in this order:
   - **What needs you**: one decision, as a yes or no question. If nothing needs the person, say so in one line.
   - **What it read**: every source from step 1, each marked read or failed.
   - **What failed**: each failed source by name, the error, and what it means for the report.
   - **What changed**: the date of the last run, how many items are new and how many are updated, then the items.
   - **What it skipped**: each item and why.
7. Before sending, check that every source from step 1 is marked read or failed. If one is missing, the report is not finished.

## Rules
- Never write "nothing new" while a source failed. Write "nothing new in the sources that loaded" and name the ones that did not load.
- Numbers carry their meaning: "3 new, 1 updated since 10-18", not a bare count.
- One decision at the top. Other questions go below it or wait for the next run.
- The person's answer to the decision is never assumed. Wait for the yes.
