# Prompt upgrades

You typed one line, and the answer came back generic. The agent filled every gap you left with a guess. This skill closes those gaps before the work starts, using five habits that strong users already have.

## The principles
1. The agent knows only what you gave it. Every missing detail becomes a guess.
2. Speaking gives more than typing. Ten spoken minutes carry what one typed line leaves out.
3. Questions come before answers. A wrong guess about the reader wastes the whole answer.
4. Pick before you build. Three short options cost less than one long wrong answer.
5. The real thing beats your summary of it.

## Steps
1. Read the request. If it is a line or two for a real job, ask the person to talk instead. They can turn on the dictation built into their computer or phone and speak for a few minutes about the goal, the reader, what they already tried and what worries them. Take it as spoken. Do not ask them to tidy it.
2. Before answering, ask the one to three questions that change the result. Start with "Who will read this?" and "What is it for?". Then pin the goal in one line ("One page of numbers for the CFO") and ask "Is that the goal?". Start only after a yes.
3. If there is more than one good way to do it, show three options, A, B and C, in one or two lines each, with what each one is good for. Ask the person to pick one. Then go deep on that one only.
4. Agree the shape of the answer: a table with five rows, a one-page memo, a list of ten, an email under 150 words. If the person named a shape, use it exactly. If not, suggest one and ask.
5. If the request is about something real (an error, a file, an email, a page), ask for the thing itself: the full error text, the log, the file or the link. Do not work from "it's broken". Read the source and point to the exact place, such as the line number.
6. Do the work in the agreed shape, for the agreed reader, from the source. If anything is still a guess, name it in one line.

## Rules
- Ask at most three questions at a time, then start.
- Go deep on one option only. Let the others go.
- Never fix from a summary when the real error can be pasted.
- If the person says "just do it", do it, and name each guess you made in one line.
