# Day gate

Your agent waited for your yes on one post, and the post missed its slot. When you approve each step as it comes, every slot depends on when you happen to answer. This skill gets one yes for the whole day's list. After that, each approved item runs at its slot.

## The principles
1. Approve the day, not the step. One yes covers the whole list you saw.
2. See the whole package before the yes. What you approve is exactly what goes out.
3. If it is not approved, it does not run. Silence is never a yes.

## Steps
1. Collect every item planned for the day. Prepare each one as a whole package. For a post, that means the video, the cover and the caption, plus its time slot and where it goes.
2. Put all of them in one list, in one place, for example a file named for the day's date. Show each package in full, not as a summary.
3. Show the list and ask "Approve this day's list as it is?" Make any change the person asks for, then show the changed item again.
4. Next to each item, write approved or not approved. A yes to the whole list marks every item approved. Write down who said yes and when.
5. At each slot, run only the items marked approved, without asking again. Use whatever scheduler you already have to start each item at its time. Run nothing else.

## Rules
- If it is not approved, it does not run. If the list has no yes before a slot, tell the person which slots are at risk.
- Never ask again about an item that is approved and unchanged. The yes was the gate.
- If an approved item changes after the yes, it is no longer approved. Show it again and wait for a new yes.
- The list is the record. If the approval is not written there, the item is not approved.
- Optional, planned and not yet running in our own system: give the yes the evening before, so a same-morning edit cannot hold up the first slot.

## Where this comes from
scripts/PROOF.md and scripts/claude-md-posting-rule.txt come from our own system. On 25 October 2026, a text post planned for 09:00 missed both 09:00 and 11:00 while it waited for a same-day edit. Since 13 October, one morning yes has covered the day's packages (video, cover, caption), and each approved item posts at its slot without asking. These files do not show how often slots are missed, any effect on reach or revenue, or any time saved. We have decided to move the yes to the evening before, but that version is not running yet.
